# 不背高考

独立原生 Android 应用，版本 **0.1.1**，包名 `cn.local.gaokao`。将古文词义、古诗文背诵、生物填空与问答放进同一个应用；不覆盖原来的三个 App。Android 8.0 及以上，离线运行。

## 当前功能

- UI 直接复用不背古文：首页左上头像、右上签到、中间意境句子、Learn/Review 双卡与双图标底栏；个人页、我的内容、我的学习／学习偏好双标签面板、开场动画和弹层均使用原组件。科目切换放在我的内容和学习计划／偏好中，教材封面加入原分册列表。首页 Learn 是当前学习范围的新学与回练，Review 是当前科目可练的到期内容；复习不受新学册次和篇目限制。
- 古文 1444 张词卡，沿用原句回想词义、揭晓与自评；原文阅读及已有今译沿用原内容。古诗文背诵 91 篇、1312 张缺句卡，保留默写草稿、原文核对和文字差异；两种语文学科共用五册真实教材封面，教材归属不明确的内容单列，不虚构归属。
- 生物 1121 张审核卡，包含原有填空、问答与答案图片，按五册25章组织，保留真实教材封面和笔记。原题干、答案、卡片 ID 与同源 note_id 保留；同笔记多个填空当天避让，已选卡片忘记后可回练。审核边界沿用来源应用，不代表教师终审或覆盖全部高考能力。
- 每科独立每日新学额度，切换范围释放未开始预留卡；三科共用同一份 FSRS-6 Java 核心、原子事件提交、防重复、首答保护与恢复代码。各科学习数据库和偏好隔离，签到使用公共数据库，每天全应用一次。
- 古文和背诵保留四点自评、首次次日检测；生物自评忘记／困难／良好／简单，正向自评一次进入长期 FSRS，不强制四遍。生物采用统一版按本地日期的调度，不声称复刻旧 WebView 的分钟级短期学习步骤。默认保持率90%，各科可调80%–97%。四点和自评均不表示掌握。
- 背诵原始输入、文字核对结果和自评分开保存；证据、事件、首答、点数、排程与会话快照在同一事务提交。学科切换可恢复尚未提交的默写草稿。
- 我的学习按当前科目展示进度、统计与公共签到日历；我的内容保留三科复习总览。收藏词书按科保存，生物笔记按卡保存。
- 可通过系统文件选择器导出全部三科、签到和设置的 JSON 备份。恢复前预览和确认，恢复替换当前高考应用记录；数据库内容使用附加数据库事务提交，失败回滚，不修改原独立 App。当前是全量恢复，不是冲突合并。

## 记录与安装边界

原三个 App 的学习记录继续留在原应用。本版尚未导入它们的学习历史，不将原来的不同策略记录伪装为统一版作答。新应用从独立进度开始，之后覆盖更新保留新应用记录。卸载或清除数据会删除本机记录，备份需主动导出。

[最新版 APK](安装包/不背高考-最新版.apk) 约11 MiB。签名在本目录 tools/debug.keystore，后续覆盖更新须保留；不能通过卸载解决签名冲突。

2026-10-27，0.1.1通过115项词卡回归和1025项整合检查，模拟器原数据指纹恢复一致。首页、日历、个人页与学习面板截图已检查；日历布局组件与古文源码一致，签到数据改用三科公共账户。此前0.1.0已完成FSRS的4592组向量、18375项数值检查及32项个人训练检查；本次未改学习算法。最终回归与截图见 output/verification，UI源码一致性见 output/ui-parity.json。

手机此前于2026-10-26安装并启动0.1.0；本次0.1.1修正版尚未覆盖安装，当前手机未连接。原古文、古诗数据库与偏好指纹安装前后一致；生物正式包禁止 run-as，无法读取其私有数据指纹，原包未覆盖。安装记录见 output/phone-install-verification.json。系统文件选择器的真机导出／导入尚未实际验收；备份序列化、恢复、跨数据库回滚和偏好恢复已在模拟器直接验证。没有账号、云同步或语音评测。

## 开发入口

在本目录运行：

```sh
python3 scripts/dev.py check        # 内容、FSRS向量与训练检查
python3 scripts/dev.py build        # 构建并签名，更新最新版APK
python3 scripts/dev.py build-tests  # 构建独立测试包
python3 scripts/dev.py verify       # 仅在Wenyan/5556测试并恢复原数据
python3 scripts/install_phone.py --serial PHONE_SERIAL  # 只安装已通过验收的同一APK，核对原应用指纹
```

父目录也可运行 `python3 scripts/dev.py gaokao-build`、`gaokao-build-tests`、`gaokao-verify`、`gaokao-check`。本机可只读复用已有SDK/JDK。独立克隆时设置 `WENYAN_TOOLCHAIN_ROOT`，目录须包含 `jdk/*/Contents/Home`、`android-sdk/android-15`（aapt2、d8、apksigner等）、`android-sdk/android-35/android.jar` 和 `platform-tools/adb`。首次构建在被Git忽略的 `tools/` 生成独立调试签名；此签名须另行保管，GitHub不包含签名或用户记录。

- `MainActivity.java`、`ContentHub.java`、`LearningPanel.java`、`ProfileHome.java`：复用古文原生 UI；`GaokaoShell.java` 仅保留科目适配、封面、笔记和图片辅助。
- `scripts/check_ui_parity.py`：对照父项目，核对首页、导航、Learn/Review、页面框架、安全区、背景、日历、弹层、头像与个人页图标的源码一致性，构建前必须通过。
- `WordStudyPanel.java`：三科共用学习与恢复，按内容类型展示词义、缺句或生物题。
- `StudyStore.java`、`FsrsStore.java`、`Fsrs.java`：公共存储与调度；SQLite schema 12 新增独立回忆证据表。
- `SubjectRules.java`：学科标识和生物同笔记避让。
- `UnifiedBackup.java`：统一备份、验证与恢复。
- `android/assets/wenyan`、`gushi`、`biology`：已冻结可直接构建的内容；`data/content-manifest.json` 记录来源与数量。
- `scripts/prepare_content.py`：只读原项目资源和本地冻结的生物APK，重建内容与封面。可直接使用当前已冻结 assets 构建，不必重新取手机APK。生物APK来源散列保存在内容清单，源码仓库中的sources目录被忽略。
- `output/verification/`：运行报告与截图，测试包及中间产物均留在 output；不放入安装包目录。

本目录是整合后的独立应用。原项目只增加开发入口与说明，不改原三个应用的业务源码；日语应用保持独立。

## 独立仓库

源码、冻结内容、教材封面与测试夹具均随仓库保存，构建不依赖父目录项目或重新读取手机。UI一致性检查在本机优先对照原古文源码；独立克隆时对照 `reference/wenyan-ui/` 冻结基准。`prepare` 是本机来源重建工具，需要原项目和本地来源APK；通常直接使用已经冻结的assets构建。模拟器回归必须先配置专属Wenyan AVD并启动在5556端口，不可用用户手机代替测试。
